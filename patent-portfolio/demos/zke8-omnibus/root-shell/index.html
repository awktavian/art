Controls

The shell has no codec knobs: its picture is the carrier field and the argmax over the 240 roots. Amplitude moves the field's reach, so it changes which family wins, which is why it is a control.

Seed law. house is this repo's convention: Xorshift128+ over an FNV-1a hash of the seed string. estate is js/seed-stream.js, a bit-exact port of Kagami's own stream — SHA-256 in counter mode over a canonical seed prefix, big-endian 64-bit words, 53-bit draws (packages/kagami/core/omni/prng.py). Both laws fill the SAME eight carrier lanes from the same mapping, so the law is the only thing that changes when you switch it. The estate law is graded, not asserted: tools/gen-estate-seed-vectors.py runs the real Python module, tools/determinism-harness.mjs compares this browser port to its bytes, and tools/browser-check.mjs re-grades the estate frame in Chromium against its own row in tools/pin.json.

What the pixels mean

  • Hue — the estate's root index 0..239 over 240 bands. The colour wheel IS the code, not a palette.
  • Value — max over the shell / its largest possible value (A·sqrt(2) for the half-shell, 2A for the integer shell).
  • Gold seam — the two families tie: (±1,±1,0⁶) (112 rows) against (±½)⁸ with an even minus count (128 rows).
  • Ice wall — the two largest lanes nearly tie, so the argmax pair changes hands: a Weyl chamber wall.
  • Magenta — an undeclared class: impossible here by construction, so if it ever appears it is a real defect, loud.

The port's one genuinely new leg: a closed form for root_index

The estate's root_index is an argmax over 240 rows with a first-occurrence tie rule (e8_period_codec.py:696-719, order fixed by dimensions.py:233-291). That is ~1920 fused multiply-adds per pixel — fine on a CPU, ruinous per fragment. The port replaces the scan with arithmetic: the maximiser of ⟨root, v⟩ is determined by the two largest magnitudes (family 1, 112 rows) or by the parity-corrected sum of magnitudes (family 2, 128 rows), and the index then follows from two integer ranks — pairRank over the 28 lexicographic pairs and rankEvenPopcount over the 128 even-popcount sign patterns. Ties are resolved by the minimum integer candidate, which reproduces the table's first-occurrence rule rather than approximating it.

The claim is checked, not asserted: the harness requires the analytic index to equal the table index over the estate's own vectors, 200k random vectors, dense tie grids, all 240 roots and their negations, and dyadic probes — 202,551 samples, 0 mismatches, 226 of them exact shell ties. The browser re-runs an independent 20,000-vector version of that falsifier at load and prints the count.

Cited in the shipped source: root generation order kagami_math/dimensions.py:233-291; table build e8_period_codec.py:610-613; root_index and its tie rule :688-694, 696-719; exact-coordinate guard :186; covering radius :189; the alphabet's class counts e8_alphabet.py:105-121.

Why the demoscene form, and what it is not

A root system is a tessellation, and tessellations are the natural subject of a realtime frame: the walls are lines, the chambers are plates, and the code changes hue exactly where the lattice changes its mind. Nothing here is a JIT: the estate's JIT legs compile the CPU decoder to a dylib (e8_jit.py) and to wasm32 (e8_wasm.py), and its shader machinery (core/code_intel/shader_declarations.py) parses WGSL and Metal declarations. There is no compile-to-GLSL path in the estate to port, so this page transcribes the math by hand and keeps every citation in the source it came from.
